# AGENTS.md

## Проєкт

Це навчальна копія публічного сайту Фундації Лятошинського: відвідувач знайомиться зі спадщиною Бориса Лятошинського, архівом, новинами та способами підтримати місію фонду. Застосунок на Next.js і TypeScript; тексти українською та англійською, дані живуть у пам’яті і не залежать від зовнішніх сервісів. Оригінал клієнта: [lf-client](https://github.com/Liatoshynsky-Foundation/lf-client). Репозиторій — шаблон курсу spec-driven-ba-workshop.

## Основні сторінки

Маршрути під префіксом мови: `/uk/...` (основна) і `/en/...`.

| Маршрут | Бізнес-призначення |
| --- | --- |
| `/` | Головна: вхід у спадщину композитора і заклик підтримати українську музичну культуру |
| `/about-us` | Про Фундацію: місія та цілі |
| `/biography` | Життєпис Бориса Лятошинського |
| `/artistry` | Творчість: твори та музична спадщина |
| `/research` | Дослідження та наукові роботи |
| `/archive` | Каталог архіву: фонди з документами, листами, афішами, рукописами |
| `/archive/[fund]` | Один архівний фонд і його справи |
| `/archive/[fund]/[case]` | Одна справа: перегляд конкретних архівних матеріалів |
| `/news` | Новини, події та згадки в медіа |
| `/cooperation` | Співпраця для партнерів, благодійників і меценатів |
| `/support-us` | Підтримка: благодійні внески на рахунок Фундації |
| `/contacts` | Контакти та запити; відповідь протягом кількох робочих днів |
| `/war-in-ukraine` | Робота Фундації та її ініціативи під час війни |
| `/privacy-policy` | Як збирають, використовують і захищають персональні дані |
| `/terms` | Правила користування сайтом, доступ до матеріалів і обов’язки користувача |

`/api-docs` — службова документація API, не публічна сторінка для відвідувача.

## Конвенції

- Код пишеться на TypeScript.
- Експортуйте іменовані експорти. Не використовуйте `export default`.
- Основна мова інтерфейсу — українська (`uk`). Англійська (`en`) — друга локаль. Новий текст спочатку з’являється в `i18n/messages/uk.json`, дзеркально — в `en.json`.

## Навчальний репозиторій

Це демо для воркшопу, а не бойове середовище. Під час `npm run dev` піднімається in-memory MongoDB і щоразу наповнюється демо-даними. База скидається при кожному запуску і зникає після зупинки застосунку. Зміни в даних через UI не зберігаються між перезапусками.
